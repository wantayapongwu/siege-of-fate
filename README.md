# Siege of Fate: เว็บ (เล่นในเบราว์เซอร์) + เซิร์ฟเวอร์ออนไลน์ บน Vercel

## โครงสร้าง
- `public/`: ตัวเกม (Godot 4.5 HTML5 แบบไม่ใช้เธรด)
  - `/` = ตัวเกม
  - `/rooms.html` = รายชื่อห้องออนไลน์
- `api/`, `lib/`: เซิร์ฟเวอร์ (Vercel Functions)
  - `/api/auth`: สมัคร/ล็อกอิน (รหัสผ่านเก็บแบบ scrypt)
  - `/api/rooms`: รายชื่อห้อง
  - `/api/signal`: ส่งต่อข้อมูลเชื่อมต่อ WebRTC ให้ผู้เล่นบนเว็บต่อกันตรง
  - `/api/health`: ตรวจสถานะ

## มัลติเพลเยอร์
- **เวอร์ชันเว็บ:** ต่อกันแบบ WebRTC (ผ่านเบราว์เซอร์) โดยใช้ Vercel แค่แลกข้อมูลการเชื่อมต่อ ข้อมูลเกมวิ่งตรงระหว่างผู้เล่น
- **เวอร์ชัน PC:** ต่อกันแบบ ENet/UDP
- ห้องของเว็บกับ PC แยกกัน จึงเล่นข้ามกันไม่ได้

## ต้องมี Upstash for Redis
บัญชีผู้เล่น รายชื่อห้อง และข้อมูลการเชื่อมต่อต้องเก็บใน Redis ไม่อย่างนั้นข้อมูลจะหายเมื่อเซิร์ฟเวอร์เริ่มใหม่ วิธีเพิ่ม:
1. ไปที่ Project > Storage > Create Database
2. เลือก Upstash for Redis (ฟรี) แล้ว Connect กับโปรเจกต์
3. Redeploy
