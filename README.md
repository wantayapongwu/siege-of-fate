# Siege of Fate: เว็บ (เล่นในเบราว์เซอร์) + ล็อบบี้ออนไลน์ บน Vercel

- `public/` ตัวเกม (Godot 4.5 HTML5 แบบไม่ใช้เธรด รันได้ทุกเบราว์เซอร์ ไม่ต้องตั้ง COOP/COEP)
  - `/` = เข้าเกม
  - `/rooms.html` = รายชื่อห้องออนไลน์
- `api/` + `lib/` ล็อบบี้ (Serverless)
  - `/api/rooms` = รายชื่อห้อง
  - `/api/health` = ตรวจสถานะ

## Deploy
```
npx vercel@latest --prod        # รันในโฟลเดอร์นี้ ตั้งชื่อโปรเจกต์ siege-of-fate
```
จากนั้นที่แท็บ Storage เพิ่ม **Upstash for Redis** (ฟรี) แล้ว deploy ซ้ำ เพื่อให้รายชื่อห้องเก็บถาวร

## ข้อจำกัดของเวอร์ชันเว็บ
- เบราว์เซอร์ส่ง UDP ไม่ได้ จึง **สร้าง/เข้าร่วมห้องออนไลน์ไม่ได้** (เล่นคนเดียวได้ครบ และดูรายชื่อห้องได้)
- เล่นออนไลน์กับเพื่อนต้องใช้เวอร์ชัน PC
- เซฟเก็บในเบราว์เซอร์ (IndexedDB) แยกตามเครื่อง/เบราว์เซอร์
