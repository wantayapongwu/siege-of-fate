เครื่องนี้ยังเปิด WebGL2 ไม่ได้

เกมต้องใช้การเร่งความเร็วกราฟิก (WebGL2) ของเบราว์เซอร์ — ตัวเกมไม่ได้เสีย แค่ต้องเปิดค่านี้ก่อน

  1. Chrome: เปิด chrome://settings/system (Edge ใช้ edge://settings/system) แล้วเปิด “ใช้การเร่งความเร็วกราฟิกเมื่อพร้อมใช้งาน” → ปิดเปิดเบราว์เซอร์ใหม่
  2. เช็กที่ chrome://gpu บรรทัด WebGL2 ต้องขึ้น Hardware accelerated
  3. ถ้ายังไม่ได้: chrome://flags ค้นคำว่า ignore-gpu-blocklist ตั้งเป็น Enabled แล้วกด Relaunch
  4. ยังไม่ได้อีก = ไดรเวอร์การ์ดจอเก่าเกินไป ให้อัปเดตไดรเวอร์ (NVIDIA / AMD / Intel) แล้วรีสตาร์ตเครื่อง

ทดสอบว่าเครื่องรองรับจริงไหม: get.webgl.org/webgl2 (ถ้าหน้านั้นไม่ขึ้นลูกบาศก์หมุน = เบราว์เซอร์ยังปิด WebGL2 อยู่)
เปิดจากลิงก์ในแอป Facebook / Line? ให้กด “เปิดด้วยเบราว์เซอร์” (Chrome / Safari) แทน
แนะนำ Chrome, Edge, Firefox หรือ Safari รุ่นใหม่ บนเครื่องที่มีการ์ดจอไม่เก่ากว่าปี 2012

เกมยังไม่ได้ใช้การ์ดจอของเครื่องนี้

ตัวที่เรนเดอร์อยู่จริง: -

1. เปิดการเร่งความเร็วกราฟิกในเบราว์เซอร์

  1. เปิด chrome://settings/system (คัดลอกไปวางในช่องที่อยู่เว็บ)
  2. เปิด “ใช้การเร่งความเร็วกราฟิกเมื่อพร้อมใช้งาน” (Use graphics acceleration when available) แล้วปิดเปิดเบราว์เซอร์ใหม่
  3. เช็กผล: chrome://gpu บรรทัด WebGL2 ต้องขึ้น Hardware accelerated
  4. ถ้ายังไม่ขึ้น: chrome://flags ค้นคำว่า ignore-gpu-blocklist ตั้ง Enabled แล้วกด Relaunch
  1. เมนู ☰ > การตั้งค่า (Settings) > ทั่วไป (General) > เลื่อนลงไปหัวข้อ ประสิทธิภาพ (Performance)
  2. เอาเครื่องหมายถูกออกจาก “ใช้การตั้งค่าประสิทธิภาพที่แนะนำ” แล้วติ๊ก “ใช้การเร่งด้วยฮาร์ดแวร์เมื่อพร้อมใช้งาน”
  3. ปิดเปิด Firefox ใหม่ แล้วเช็กผลที่ about:support หัวข้อ Graphics ต้องขึ้น WebGL 2 Driver Renderer เป็นชื่อการ์ดจอจริง

ตั้งให้ Windows ส่งเบราว์เซอร์ไปใช้การ์ดจอแยก

  1. คลิกขวาที่หน้าจอ > การตั้งค่าการแสดงผล (Display settings) > กราฟิก (Graphics)
    Windows 11: การตั้งค่า > ระบบ > จอแสดงผล > กราฟิก  |  Windows 10: การตั้งค่ากราฟิก
  2. กด เพิ่มแอปเดสก์ท็อป แล้วเลือกไฟล์ของเบราว์เซอร์ที่ใช้เล่น
    C:\Program Files\Google\Chrome\Application\chrome.exe
    Windows 11 รุ่นใหม่เลือกจากรายชื่อแอปที่ติดตั้งไว้ได้เลย ไม่ต้องหาไฟล์
  3. กดที่รายการนั้น > ตัวเลือก > เลือก ประสิทธิภาพสูง (High performance) > บันทึก
  4. ปิดเบราว์เซอร์ให้หมดทุกหน้าต่าง แล้วเปิดใหม่ (ไม่ปิดหมด ค่าจะไม่เปลี่ยน) แล้วเข้าเกมอีกครั้ง

การ์ด NVIDIA ตั้งซ้ำอีกชั้นได้: คลิกขวาหน้าจอ > NVIDIA Control Panel > จัดการการตั้งค่า 3D > การตั้งค่าโปรแกรม > เลือกเบราว์เซอร์ > โปรเซสเซอร์กราฟิก = ตัวประมวลผล NVIDIA ประสิทธิภาพสูง

ที่อยู่ไฟล์เบราว์เซอร์อื่น ถ้าหาไม่เจอ — Edge: C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe · Chrome: C:\Program Files\Google\Chrome\Application\chrome.exe · Firefox: C:\Program Files\Mozilla Firefox\firefox.exe

ทำไมเกมสั่งให้เองไม่ได้: หน้าเว็บขอได้แค่ “ขอการ์ดจอตัวแรง” ซึ่งเกมขอไปให้แล้วทุกครั้ง แต่ Chrome/Edge บน Windows ผูกการ์ดจอไว้ทั้งเบราว์เซอร์ตั้งแต่เปิดโปรแกรม (Opera, Brave และ Chromium ตัวอื่นก็ตัวเดียวกันหมด) จึงไม่สลับตามคำขอของหน้าเว็บ — สวิตช์จริงอยู่ที่ Windows เท่านั้น (Firefox กับ Mac สลับตามคำขอให้เอง)
เล่นต่อได้เลยถ้าไม่สะดวกตั้งตอนนี้ แต่ถ้าแลคมาก ลองลดที่ ตั้งค่า > กราฟิก > คุณภาพกราฟิก เป็น “ต่ำ” ช่วยได้อีกทาง
